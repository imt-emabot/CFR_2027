# Robot principal

Tout ce qui constitue le robot principal : électronique, mécanique, logiciel.

- [`elec/`](elec/) — cartes électroniques du robot.
- [`meca/`](meca/) — pièces et sous-ensembles mécaniques.
- [`logiciel/`](logiciel/) — workspace ROS 2 embarqué.

L'architecture, les choix actés et leurs motifs vivent dans `docs/cdc/cdc-logiciel-robot-v1_0.md` ;
ces dossiers n'en sont que la structure de code (règle 5 de `docs/cdc/conventions-cdc.md`).
