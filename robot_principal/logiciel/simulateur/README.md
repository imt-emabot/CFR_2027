# Simulateur

Pont entre le format d'enregistrement/rejeu du robot et un simulateur, pour rejouer un
match capturé sans le matériel (CDC logiciel, section 5.7 et section 19).

Renvois : format d'enregistrement (section 19.3), le lecteur (section 19.4), le pont vers
le simulateur proprement dit et son ordre de réalisation (sections 19.5 et 19.6).
